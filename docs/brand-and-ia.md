# 个人品牌概念、信息架构与音视频方案

> 站点名：**张栋栋 / 北省 · 读片报告**  
> 核心句：**让模型，在真实系统里跑起来。**  
> 副线：**从一张切片，到一条产线。**

---

## A. 三个创意概念（为什么是现在这个）

### 概念 1 · 读片台 / Reading Room（采用）

- **核心隐喻**：个人网站是一份「个人读片报告」。纸本报告负责可靠与可读，医学影像灯箱负责产品感与动态证据。
- **首屏**：报告头（受检者 / 方向 / 地点 / 2026.10）+ 半调肖像 + 朱印 + 一块灯箱。灯箱里有 P-00 介绍片与 P-01…P-07 七个检查项；切 tab 会换影像/数据板与「检查所见」。
- **视觉母题**：纸 `#F3EBDD`、墨 `#1B1813`、石墨 `#12100D`、骨白 `#EDE4D3`、朱砂 `#B23A2A`；衬线标题 + 等宽数据 + 细线/小圆角；DICOM 角标、切片框、印刷色条、套准线。
- **声音标识**：三音「扫描动机」（约 659→988→1047 Hz），默认关闭，只在切换检查项 / 打开影片时出现。
- **项目如何变章节**：不是卡片墙，而是「感知 → 理解 → 决策 → 执行 → 交付」五章；每章只放能证明这件事的项目。
- **风险/降级**：医学隐喻密度过高会劝退非医疗雇主 → 每章都有中文直白副标题与一句话定位；动画只做交互反馈；影片失败仍有 poster、文字稿、音频版。

### 概念 2 · 交付现场 / The Delivery Floor

- **隐喻**：个人网站是一座「交付现场」——MES 工位、迁移看板、上线灯。
- **首屏**：一块生产看板，七个项目是七条产线；指标是产量/良率/停机时间。
- **视觉**：工单黄、警示橙、蓝图网格、等宽字；更工业。
- **声音**：产线启动、扫码枪、对账通过的提示音。
- **项目章节**：按「接单 → 建模 → 联调 → 灰度 → 上线」组织。
- **风险**：AI 差异化被弱化，容易变成普通企业开发作品集；对医学影像背景不友好。降级为「只做 /work 的一个视图」。

### 概念 3 · Agent 调度台 / The Orchestrator

- **隐喻**：个人网站是一台 Agent 调度台；七个项目是七个工具/子代理，访客可以下指令。
- **首屏**：终端 + 运行日志 + 实时状态；输入 `/works` 或 `/open 3` 加载项目。
- **视觉**：深色控制台、荧光绿/琥珀、等宽字；更“AI 产品”。
- **声音**：键盘、工具调用完成、流式 token 的轻响。
- **项目章节**：按「工具注册 → 调用 → 结果 → 审计」组织。
- **风险**：容易落入“AI 终端模板”，且会掩盖医学影像与全栈交付的差异化；交互门槛高。降级为 `/work` 的二级彩蛋。

**推荐概念 1**：它是唯一同时容纳「智能医学工程」的影像身份、「Agent / 规则」的判断方式、「企业系统交付」的工程可信度的框架；而且“从一张切片到一条产线”这句话只有张栋栋能讲。

## B. 信息架构

```
/                 读片台（个人展示页）
/work             检查列表（7 项目 + 本站元案例）
/work/:slug       检查报告（证据链 / 回放 / 决策 / 来源）
/posts            问题日志（文章列表）
/posts/:id        文章详情（目录 / 批注）
/wiki             知识库（30 篇 / 四层 / 三条阅读路径）
/wiki/:slug       知识文档
/resume           个人报告（网页简历 + 脱敏 PDF）
/about            自述 / 工作原则 / 时间线 / 关于本站
/archive /tags    归档 / 标签
/admin/**         本地管理（保留功能，不放入主导航）
*                 404
```

主导航 6 项：读片台 / 项目 / 文章 / 知识库 / 简历 / 关于。搜索、日/夜、声音、菜单在右侧；归档、标签、管理、RSS 在页脚。

### 页面节奏

- **5 秒**：姓名、方向、钩子句、7 项作品 / 2 套企业系统 / 30 篇知识、播放按钮。
- **30 秒**：五段能力链 + 7 个项目的一句话与指标；知道“不是单点技能”。
- **3 分钟**：点进任一项目，看到角色、证据、运行回放、决策、取舍、来源。
- **深读**：文章 / 知识库提供方法与上下文。

## C. 个人符号系统

1. **切片框（Slice Mark）**  
   方框 + 左上红角 + 一条扫描线，内部可放 BS / 编号 / 章节号。  
   解释：影像阅片一次只看一片；工程判断一次只认一条证据。  
   出现位置：页头 logo、章节号、文章眉标、项目编号、页脚。

2. **半调肖像（Halftone Portrait）**  
   用户提供的 `Blog.jpeg` 经 9px 网点、纸/墨双色、套准十字处理，成为“档案标本照”，不是普通圆头像。  
   出现位置：首页报告头、关于页、简历 PDF 的视觉身份。

3. **朱印（Seal）**  
   “张栋栋 / 北省”方形印章，轻微旋转。  
   解释：报告签发、个人署名、中文身份。出现位置：报告头、首页签发、关于、页脚。

4. **扫描线与套准线（Scan / Registration）**  
   灯箱内的细扫描线、章节左上角的套准角、页脚的色条。  
   解释：这是“被检查过的证据”，不是装饰。

5. **三音扫描动机（Sound Motif）**  
   659→988→1047 Hz 的短动机；默认关闭，只在用户开启声音后、切换检查项/打开影片时播放。  
   解释：像超声/监护仪的一次扫描，不循环、不打扰。

6. **印刷色条（Color Bar）**  
   朱砂 / 墨 / 玉 / 纸四色小方块 + `BS-2026-10 / PLATE 01`。  
   解释：这是一份被印刷、被归档的报告。

## D. HyperFrames 影片方案

- 片名：《从一张切片，到一条产线》
- 48s / 1920×1080 / 24fps / 中文旁白 + 字幕 + 程序化环境垫乐
- 六个镜头：冷开场 MRI → Lite-Mamba → Qwen3 服务 → 合同规则引擎 → MES/迁移 → 片尾。
- 视觉：石墨灯箱、纸/骨白字、朱砂标注、灰度真实截图、等宽数据；无远程字体、无渐变、无粒子。
- 嵌入：首页 P-00 tab；poster 先行，点击才加载 MP4；附文字稿与音频版；不自动播放声音；移动端全宽。
- 降级：poster / 文字稿 / 音频版 / 示意图；reduced-motion 关闭扫描动画。
- 详细分镜与脚本见 `video/profile-film/STORYBOARD.md`（由影片工程维护）与本仓库 `docs/brand-and-ia.md` 的影片章节。
