## 2. 逐镜脚本

### S00 · 灯箱亮起 / 封面

- **时间**：0:00–0:03（3s）
- **空间**：00 封面 / 灯箱
- **剧情功能**：建立「这是一份报告」的世界；受检者一栏是空的。
- **画面**：
  - 全黑。先听到灯箱启辉的「咔」，画面从中心亮起一块暖白的长方形；光从纸下面透上来，纸的纤维可见。
  - 一张 A3 报告封面躺在灯箱玻璃上。顶部：`PERSONAL READING REPORT / VOL.07 / BS-2026-10`。左上：套准十字。右上：一张空白的肖像框，框里只有极淡的半调网点，没有脸。
  - 受检者：`—`。方向：`全栈开发 · AI 应用`。地点：`湖北 · 武汉`。状态：`可实习 · 2027 届`。检查项目：`寻找受检者`。
  - 右下：一枚红色小方块（切片框的红角）在纸面上，像一颗种子。
- **相机**：
  - 位置：封面上方 30cm，正俯拍（90°）。
  - 镜头：50mm；光圈 f/4；焦点在「受检者」空白栏。
  - 运动：macro-drift，从左向右 1.5cm/s，极慢；高度不变；无滚转（画面正立）。
  - 速度曲线：0.3x → 0.4x，匀速偏慢。
- **小片**：未出场。0:02.5，红色小方块脉冲一次（2px 放大 + 回弹），像心跳。
- **屏幕文字**：报告头、字段、`检查项目：寻找受检者`。
- **声音**：
  - 0:00 灯箱「咔」+ 50Hz 嗡鸣。
  - 0:01 纸页落下、纸张回弹。
  - 0:02 三音动机的第一个音 C5，极轻。
- **旁白**：无。
- **转场**：无。本镜是长镜头的起点。
- **实现备注**：封面用 HTML 重建，保证文字清晰；纸纹和灯箱光用 CSS 纹理 / 径向光；不要用现成海报图。

### S01 · 空白受检者 / 小片醒来 / 画「?」/ 开门

- **空间**：00 封面

- **画面**：

  - 0:04.0 小片从框里迈出一条腿，另一条腿跟上；它抖了抖身体，纸腿像纸条一样晃。它站在报告上，只有 8cm 高。
  - 0:04.8 它读报告：眼睛左右扫；看到「受检者：—」时，眼睛变成一个 4px 的点（SURPRISE），头（框）歪 8°。

  - 0:06.2 它抬头看「?」，又低头看自己的红角；决定（眼睛下斜 4°，身体前倾）。
  - 0:06.8 一枚大印章从画面上方落下：`INCOMPLETE / 待补全`，压在报告右下；纸面下陷 2px，镜头震 2px。

- **相机**：
  - 位置：小片正面 12cm；0:06 后移到门框前 6cm。
  - 镜头：50mm；光圈 f/2.8；焦点从小片的眼睛 → 空白栏 → 门框中心。
  - 运动：0:03–0:05 dolly-in 5%；0:05–0:06.5 orbit 8°；0:06.8 因印章震动 2px；0:07.2–0:08 push-through，速度 1.6x；滚转 +90°。

- **小片动作分解**：
  - 0:04.0 爬出（0.3s），落地 squash 0.9，站起。
  - 0:04.5 眨眼 ×2，左右看。
  - 0:04.8 读报告：眼睛扫视 0.6s。
  - 0:05.4 画「?」：手伸出 0.2s，画 0.5s，收手。
  - 0:06.2 决定：眼睛下斜，身体前倾，腿微蹲。
  - 0:07.2 跳起 + 展开成门（0.25s）；腿手收回；红角放大 20%。
- **屏幕文字**：
  - 0:05.2 `INCOMPLETE / 待补全`（朱砂章，斜 6°）。
  - 0:06.8 `报告在找你`（片名章，压在报告上；这是全片唯一一次出现片名）。
- **声音**：
  - 0:03 红角「滴」；0:03.4 纸框画出的沙沙。
  - 0:04 纸腿落地、纸抖。
  - 0:05 马克笔 squeak；0:06 红线抽出（细、近）。
  - 0:06.8 印章 thud + 纸面回弹。
  - 0:07.2 纸展开 + 440Hz 上行；0:08 穿过门的风声。
- **旁白**：0:04–0:08：`一份报告，在找一个不在场的人。`
- **转场**：穿过切片框。12 帧。门框内是下一间房的纸纹；相机过 z=0 时，门框边缘变成下一间房的页面边缘；滚转 +90°。
- **实现备注**：门框用 clip-path / mask；下一间房预加载在门后；纸纹方向要对齐；红角抽线用 SVG path + stroke-dashoffset。
