## 1. 为什么拍这部片

### 1.1 背景

站点已经有一部 48 秒的《博客开机自检》：无旁白，把小片当作自检员，逐项检查读片台、项目、知识库、简历、文章、影片。它证明了站点「能跑」，但它是**功能清单式的**，观众记住的是一串栏目，不是一个故事，也不是一个人。

60 秒版要解决三个问题：

- 让第一次来的人**在一分钟内感到这是一个可以走进去的地方**，而不是一页作品集。
- 让「7 项作品 / 2 套企业系统 / 30 篇知识 / 1 篇论文」这些数字**有情绪、有出处、有一个终点**。
- 让片子的最后 15 秒**真正落到张栋栋这个人身上**：不是「关于我」的旁白，而是报告找到作者、作者签下名字。

### 1.2 目标

| 层级 | 目标 | 在片中的落点 |
|---|---|---|
| 记住一个人 | 张栋栋，智能医学工程 2027 届，FDE / 软件开发，医学影像 AI · 全栈交付 | 肖像睁眼、手写「我在这儿」、签名、片尾卡 |
| 记住一件事 | 算法、服务、交付，一条链路亲手跑完 | 五章能力链、七个项目 |
| 记住一组证据 | 7 项工程 / 2 套企业系统 / 30 篇知识 / 1 篇国际会议论文 | 小片挎包上的标签，最后被摆成片尾数字 |
| 产生一个动作 | 点进站点、播放影片、看项目、发邮件 | 片尾 CTA 与「读我」 |

### 1.3 观众

- **主观众**：正在招 FDE / 全栈 / AI 应用 / 医学影像软件方向的招聘方与用人经理。他们每天看几十份作品集，耐心约 15 秒。
- **次观众**：技术同行、面试官、合作方。他们会暂停看数字，也会被一个多余的动画激怒。
- **第三观众**：偶然点进来的读者。他们不需要看懂每个项目，但需要觉得「这个人有意思」。

三种观众的共同点：**对「精致的自嗨」免疫，对「具体的事实 + 一点人味」没有抵抗力。**

### 1.4 信息优先级

1. 这是一个**人**的网站，不是模板。
2. 这个人**从影像到产线**都做过：模型、服务、规则、系统、迁移。
3. 证据是**可查的**：数字有出处，项目有角色，取舍有记录。
4. 他现在**可实习**，2027 届，武汉 / 远程可谈。
5. 联系方式**就在片尾**。

### 1.5 成功标准

| 指标 | 目标 |
|---|---|
| 完播率（站内） | ≥ 65%（60s 片子，前 5 秒必须抓住） |
| 5 秒留存 | ≥ 80% |
| 静音可看率 | 100%（无旁白，画面文字承担全部信息） |
| 点击 /work 或 /resume | ≥ 8% 的播放用户 |
| 记忆点 | 看后能说出「一份找作者的报名」「印章」「7/2/30/1」中的至少两个 |
| 制作底线 | 无穿帮剪辑、无错别字、无未授权素材、无完整手机号与客户名 |

### 1.6 限制与底线

- **无旁白**：没有配音；信息由画面文字、字幕、音效承担。静音播放也必须看懂。
- **60 秒**：每间房必须为故事服务，不为「展示完整」服务。
- **隐私**：不出现完整手机号、GPA、排名、客户真实名称；客户项目只用「某制造企业 / 某出行运营企业 / 某能源国企」。
- **事实**：所有数字来自 `src/data/works.ts`、`src/data/resume.ts`、README 与简历 PDF；没有出处的数字不进片。
- **素材**：只用站点已有资产、公开截图、重新绘制的示意图；不用图库素材、不用 AI 生成的假人脸、不伪造客户界面。
- **技术**：HyperFrames / HTML / CSS / GSAP 可实现；不依赖远程字体、CDN、实时 3D 引擎；渲染确定性。
- **结尾手**：用插画纸手，不用实拍手；保持世界观统一。

## 2. 核心创意

### 2.1 Logline

> 一份被退回的报告，缺一个受检者。
> 报告里的小读片员沿着网站去找这个人：
> 它翻了七个项目、五章能力链、三十篇知识、七篇文章、一页简历，
> 盖了满满一包章，却始终找不到一张脸。
> 最后它走进「自述」，看见一张闭着眼的半调肖像。
> 它伸出手，肖像睁开眼——
> 一行手写出现在纸上：
> 「别找了。我在这儿。」

### 2.2 一句话卖点

**把网站当成一栋可以走进去的读片室，让网站自己的符号当导游，最后让作者的手写把镜头收住。**

### 2.3 叙事诡计：批注是报告，手写是作者

没有旁白，叙述由两种字迹完成：

| 字迹 | 谁在写 | 语气 | 出现位置 |
|---|---|---|---|
| **等宽批注 / 衬线标题** | 报告本身 | 冷静、第三人称、像读片结论 | 全片前 44 秒 |
| **手写** | 张栋栋本人 | 低、近、带一点笑 | 第 45 秒起，只有三处：`别找了。我在这儿。`、签名、`报告看完了。接下来，读我。` |

前 44 秒，观众以为这是一份冷冰冰的报告在自述；第 45 秒，手写出现，笔尖的沙沙声取代了所有旁白。**「我」不是被说出来的，是被写出来的。** 这就是无旁白版的「视角落地」。

### 2.4 为什么是一镜到底

- **主题上**：读片是一次连续的阅读，不该被剪辑打断。镜头从封面读到签名，就是观众把这份报告读完。
- **结构上**：网站本身就是一页一页的报告。每一页是一间房；镜头穿过页面，就是翻页。没有切点，观众不会问「现在到哪了」，只会问「下一页是什么」。
- **角色上**：小片是一个方框。它可以把身体展开成一扇门。**转场由角色完成，不由剪辑完成。**
- **60 秒上**：一镜到底让 60 秒像一次坠落，而不是十支广告拼在一起；删掉剪辑点，也删掉了「又一段开始」的疲劳。

### 2.5 为什么是「小片」

站点里已经有一个反复出现的符号：**切片框**——方框、左上红角、一条扫描线。它是页头 logo、章节号、项目编号、页脚标记，也是「一次只看一片」的工作方式。

把小片做成角色，有三个好处：

1. **品牌一致**：观众看完片子，再回到网站，会在每个角落认出它。
2. **形态自由**：方框可以变成门、窗、胶片格、印章、光标、放大镜、报告封面；一个角色解决所有转场。
3. **性格反差**：它是一板一眼的读片员，却总被纸、卡、电影和数字绊倒。机器的认真与人的随意之间的落差，就是趣味来源。

### 2.6 为什么是「报告」

「个人读片报告」是站点最强的差异化。它不是又一个作品集模板，而是一个**有格式、有证据、有签发人**的东西。片子的开头是「报告缺一个受检者」，结尾是「报告被签发」——故事和品牌是同一件事。

片名从《报告在找你》改成《一份报告的旅行》，把重心从「寻找」移到「旅程」：**网站不是背景板，是报告走过的地方。** 每一页都是它去过的一站。

### 2.7 主题

**证据可以证明你做过什么，但只有你能签下自己的名字。**

小片相信「读完了就能找到人」；它收集印章、指标、卡片、简历，把人拆成可核对的数据。最后它发现：数据能证明能力，不能代替那个坐在桌前的人。它放下「读」，学会「看」；它不再只是报告上的一个记号，而成为报告最后的印章。

### 2.8 60 秒情绪曲线

```
好奇 ──→ 加速 ──→ 过载 ──→ 停住 ──→ 安静 ──→ 温暖 ──→ 落定
0:00      0:08      0:20      0:36      0:41      0:45      0:55
```

- **0:00–0:08 好奇**：一份缺人的报告，一个小人决定去找。
- **0:08–0:20 加速**：读片台、七个项目、五章能力链，信息密度最高。
- **0:20–0:36 过载**：知识库雪崩、文章走钢丝、简历攀爬；小片被信息淹没。
- **0:36–0:41 停住**：它在肖像前停住；数据里没有脸。
- **0:41–0:45 安静**：自述室，五条原则，几乎无声。
- **0:45–0:48 温暖**：肖像睁眼，手写「我在这儿」，手接住它。
- **0:48–1:00 落定**：签名、印章、片尾卡。

| 关键词 | 具体装置 | 在片中的位置 |
|---|---|---|
| **故事性** | 目标（找到受检者）→ 障碍（数据里没有脸）→ 转折（肖像睁眼 / 手写出现）→ 解决（签名 / 变成印章）。每间房给一个「证据」，但没有一间给「人」。 | 0:04 目标；0:43 停住；0:45 转折；0:48 解决 |

## 3. 世界：一栋读片室

### 3.1 空间法则：每一页是一间房

片子不把网站拍成「屏幕」，而是拍成**一份立起来的报告**。报告的每一页是一间房，房间之间有物理连接：

- 页面是地面、墙、天花板；字体是建筑；按钮是家具；数据是灯。
- 报告是**垂直堆叠**的。镜头从封面往下坠，穿过一页又一页；每一页的重力方向由页面决定，所以镜头会滚转 90°、180°。
- 片尾，镜头从最后一页**拉回**，观众第一次看见整份报告躺在灯箱上——所有房间只是同一张桌上的纸。

这条空间逻辑让一镜到底有终点：**从封面出发，回到封面。**

### 3.2 光 / 纸 / 红线：三条物理规则

| 元素 | 规则 | 作用 |
|---|---|---|
| **灯箱** | 全片唯一主光源，永远在画面左上；色温偏暖，边缘有轻微衰减；灯箱的 50Hz 嗡鸣是环境底噪 | 让每个房间像被同一盏灯照着；片尾灯箱渐暗，只留纸的余温 |
| **纸** | 所有表面都是纸：有纤维、有厚度、有回弹；折叠有折痕，撕裂有毛边；不出现塑料、玻璃、金属高光 | 让网站可信、可触摸；让「报告」不是比喻 |
| **红线** | 从 小片 的左上红角抽出来的一根朱砂线；它是「寻找」的实体化；穿过每一页，最后系在印章上 | 一镜到底的视觉脊柱；观众的眼睛跟着它走；它也是相机的引导线 |

**红线的物理**：细、轻、略有弹性；被拉长时会绷紧，松开时会回弹；穿过纸面时留下一个极小的红点；在风中会飘，但不会乱飞。它不能被剪断，只能被系上。

### 3.6 连续性锚点

每一间房都必须出现、且位置一致的六件事：

1. **左上红角**：小片的红角，或页面左上角的套准角。
2. **红线**：从上一间房带进来，从下一间房带出去。
3. **纸纹与颗粒**：全片同一张纸，颗粒不换。
4. **灯箱的光**：永远从左上打来，色温一致。
5. **印章的重量**：每次盖章都有纸面下陷和 2px 的镜头震动。
6. **报告编号**：`BS-2026-10` / `VOL.07` 在每间房的角落出现一次。

## 4. 主角：小片 / S-00

### 4.1 身份与来历

- **名字**：小片。
- **代号**：S-00（Slice 00）。
- **身份**：站点「切片框」符号活过来的读片员；这份报告的最后一个读者。
- **来历**：报告被退回时，左上角的红角闪了一下，它从方框里爬出来。它不知道自己是被谁画出来的，只知道报告上「受检者」一栏是空的。
- **工作**：找到受检者，让报告被签发。
- **年龄**：和这份报告一样大（报告编号 BS-2026-10）。
- **住址**：报告每一页的左上角。

### 4.2 欲望 / 需求 / 缺陷 / 弧光

| 项 | 内容 |
|---|---|
| **想要（Want）** | 找到受检者，把报告签完，让自己这份报告「生效」。 |
| **需要（Need）** | 明白人不是数据的总和；它不需要「找到」一个人来证明报告有价值，它本身就是报告的一部分。 |
| **缺陷（Flaw）** | 太相信证据。它以为只要章盖得够多、卡片读得够全，就能拼出一个人的脸。 |
| **恐惧（Fear）** | 成为一份永远没有签名的报告——空白、无效、被退回收发室。 |
| **弧光（Arc）** | 从「收集」到「看见」；从「报告上的记号」到「报告最后的印章」。它不再问「人在哪」，而是问「你在这儿吗」。 |
| **口头禅** | 无台词。只有一声 880Hz 的短鸣，意思是「收到」「here」「嗯？」 |

### 4.5 表情系统

| 状态 | 眼睛 | 身体 | 用在 |
|---|---|---|---|
| IDLE | 一条 48px 的横线，瞳孔居中 | 轻微呼吸 2px | 常驻 |
| BLINK | 横线压到 15% 高度，0.12s | 无 | 每次停顿、每次「嗯？」 |
| LOOK | 瞳孔左/右移 12px，0.18s | 头（框）转 3° | 看向下一个动作 |
| SURPRISE | 横线变成一个 4px 的点 | 整体拉长 1.08，腿离地 2px | 看到第 8 张卡、肖像睁眼 |

### 4.6 动作库

| 动作 | 帧数 / 时长 | 描述 | 声音 |
|---|---|---|---|
| 走 | 8 帧循环 | 两条纸腿交替，身体上下 2px | 纸步 1.2kHz |
| 跑 | 4 帧循环 | 身体前倾 8°，腿交替 12px，包飞起 | 纸步加快 + 风声 |
| 跳 | 0.3s | 蹲 0.08s → 起跳 → 空中收腿 → 落地 squash 0.9 | 纸弹 + 落地 |
| 滑 | 0.5s | 一脚前一脚后，身体后仰 | 纸摩擦 |
| 爬 | 6 帧循环 | 手抓、腿蹬，身体贴墙 | 纸摩擦 + 轻哼 |
| 盖章 | 0.15s | 手臂举起 → 快速下压 → 身体前倾 → 回弹 | 印章 thud |
| 拉 | 0.4s | 双手抓纸边，身体后仰，脚打滑 | 纸拉伸 |
| 指 | 0.2s | 一只手臂伸出，指向目标 | 880Hz 短鸣 |
| 展开成门 | 0.25s | 腿手收回，框放大到 1.5 倍，中间透空 | 纸展开 + 440Hz 上行 |
| 折叠成印章 | 0.5s | 框变实心朱砂，红角变成「北」字，眼睛变成边框 | 低频 + 印章 |
| 被埋 / 爬出 | 0.8s / 1.2s | 卡片落下，只露一只脚；爬出时头顶一张卡 | 卡片雪崩 + 纸抖 |
| 挥手 | 0.6s 循环 | 一只手臂左右摆，身体轻晃 | 880Hz 两声 |

**动画原则**：

1. **有重量**：落地必 squash，起跳必 anticipation；不做无重力的漂浮。
2. **有纸性**：转身时框会略微弯；跑动时腿像纸条一样甩；被风吹时会翻面。
3. **有停顿**：每次大动作前停 2 帧，让观众看清意图。
4. **有指向**：它的眼睛和身体永远指向下一个动作；观众跟着它看。
5. **不过度**：它是读片员，不是杂技演员；每间房只做 1–2 个高光动作。

### 4.7 与界面的交互规则

- **一次只碰一个控件**：按钮、卡片、标签、搜索框、进度条；一次交互只产生一个结果。
- **交互必须可见**：按下去要下陷 2px；拉开要看到纸的折痕；盖章要留下章；点击要有 880Hz。
- **不遮正文**：小片站在字的外侧、页边、标点上方；遮挡标题不超过 0.4s。
- **不改变事实**：它盖的章是「已读 / 证据 / 收到」，不修改任何指标；数字永远是站点里的数字。
- **尊重网格**：它站在 12 列网格的线或交点上；不随意漂浮在段落中间。
- **第四面墙**：只在三处看镜头——知识库的「作者?」空白卡、手写出现的瞬间、片尾挥手。其余时间它不知道镜头存在。

### 4.8 声音

- **专属音**：880Hz、60ms 的方波短鸣；音高不变，只变节奏。两声 = 收到；三声 = 疑问；一声长 = 叹气。
- **脚步**：1.2kHz 的纸面轻点；跑动时加一层 200Hz 的纸箱共鸣。
- **盖章**：90Hz 的低频 thud + 纸面拍击；不同房间的混响不同（影院更长，纸室更干）。
- **展开成门**：纸展开的沙沙 + 440Hz 上行滑音。
- **不说话**：没有配音、没有拟人台词；它的「语言」是节奏和动作。
- **全片唯一的人声**：笔尖。第 45 秒手写出现时，只有笔尖划纸的声音；这是「我」。

### 4.9 禁止事项

- 不做嘴、不做牙、不做舌头。
- 不做人类手指；手是纸带，末端是斜切。
- 不做毛绒质感、不做高光、不做 3D 倒角。
- 不做爱心、星星、汗滴、愤怒符号等表情包。
- 不做无意义的常驻漂浮；它必须站在某个东西上。
- 不抢文字；它不是 logo 动画，是角色。
- 不在悲伤 / 安静的时刻做滑稽动作；喜剧只在它「太认真」时发生。

### 4.10 角色小传（第一人称）

> 我是一份报告的左上角。
> 平时我只是一条框、一个红角、一条扫描线。

## 5. 配角与道具

### 5.1 报告

- **角色**：舞台、证据、另一个「角色」。它是被退回的、缺一个受检者的报告。
- **状态变化**：空白 → 被读 → 被盖章 → 被签名 → 被签发。
- **视觉**：A3 纸，报告头、字段、套准线、页码、色条；纸角有轻微卷曲；灯箱从下面打光。
- **关键道具**：`INCOMPLETE` 红章（序幕）、七枚项目章（检查所见）、`已读` 章（文章）、`CV` 章（简历）、最终印章（签发）。

### 5.2 红线

- **来源**：小片的左上红角。红角是线轴；它拉出红线，红线穿过每一页。
- **功能**：寻找的实体化；相机的引导线；转场的缝合线；片尾系住印章。
- **物理**：轻、韧、略弹；拉紧时变细，松开时回弹；穿过纸面留下红点；不能断。
- **情绪**：越到后面越长、越重；在自述室几乎垂到地上；被作者接住后，红线松开，绕在印章上。

### 5.3 肖像 / 作者（插画手，已确认）

- **形象**：站点现有的半调肖像（`public/portrait-halftone.webp`）：闭眼、微笑、BS 衬衫、网点。
- **片中状态**：一直闭眼；第 45 秒睁眼；看向小片；嘴角微动；一只**插画纸手**从肖像里伸出来，接住小片。
- **表现方式**：2.5D 半调分层（头发、脸、衬衫、网点），网点可波动；手是同一套墨线风格的纸手；**不用实拍手、不做写实人脸、不做 AI 换脸**。
- **手写**：全片只有三处手写——`别找了。我在这儿。`、签名 `张栋栋`、`报告看完了。接下来，读我。`。手写用作者真实笔迹矢量，不用字库手写体。
- **声音**：没有配音；笔尖划纸就是「人声」。如果作者愿意，可以录一段笔尖声作为声音素材，但不出现人声。

### 5.4 印章

- **形象**：站点现有的「张栋栋 / 北省」朱印，2px 红边、宋体、轻微旋转。
- **片中状态**：前 47 秒不存在；第 48 秒，小片折叠成它。
- **功能**：报告生效；小片的成年形态；片尾 logo。
- **细节**：印章的「北」字第一笔里，藏着一条 4px 的扫描线——小片的眼睛在印章里眨了一下。

### 5.5 灯箱

- **形象**：一块从下面发光的磨砂玻璃；边缘有黑色卡纸框；四角有套准角。
- **功能**：全片唯一主光源；片头亮起，片尾渐暗。
- **声音**：50Hz 嗡鸣；亮起时「咔」一声；熄灭时「哒」一声，然后只剩纸的声音。

### 5.6 观众（画外）

- **身份**：镜头的持有者；读报告的人。
- **存在方式**：不出现；但小片在知识库「作者?」卡、手写出现的瞬间、片尾看镜头，就是在看观众。
- **片尾**：「报告看完了。接下来，读我。」——这句话是对观众说的，不是对小片说的。

### 5.7 彩蛋（可选，不占主片时长）

- **404 房间**：片尾字幕滚完后的 3 秒，小片打开一扇写着 404 的门，掉下去，又爬上来，举着一块「这份报告不在卷内」的牌子。适合社媒版，主片可放在片尾字幕之后。
- **日夜切换**：如果做 15s teaser，可以让小片按一下「夜间」按钮，整个房间熄灯，只剩它的红角。
- **声音开关**：小片按一下「声音 关」，全片静音 1 秒，它自己「啊？」一声（只有字幕），再按开。只在预告里用，主片不用。

## 6. 故事

### 6.1 三幕

| 幕 | 时间 | 地点 | 任务 | 转折 |
|---|---|---|---|---|

### 6.3 人物弧光

**小片**

- 起点：一个记号，一份被退回的报告，一个空白的「受检者」。
- 中点：它拥有了满满一包印章，却越来越不确定「人」在哪里。
- 终点：它不再试图把人变成数据；它让作者签下名字，自己成为印章。它从「报告的一部分」变成「报告的落款」。

**作者（手写 / 肖像）**

- 起点：一个不在场的名字，一份冷冰冰的报告。
- 中点：观众开始怀疑这份报告是谁写的。
- 终点：肖像睁眼，手写出现；他承认自己就是报告要找的人，也是写报告的人。

**观众**

- 起点：看一个可爱的小人逛网站。
- 中点：被信息密度推着走，开始好奇「这到底是谁的网站」。
- 终点：意识到自己也被「读」了——片尾的「读我」是对观众说的。

### 6.5 结尾的三种读法

1. **关于作者**：报告找到了写它的人；网站是张栋栋给自己写的读片报告。
2. **关于读者**：报告也在找每一个读它的人；「读我」是邀请，不是口号。
3. **关于作品**：报告不需要一个完美的结尾，只需要一个签名；作品也是。

## 7. 一镜到底的镜头调度

### 7.1 十条规则

1. **零剪辑点**：全片只有一个镜头；所有转场都是相机穿过一个物理开口（门、屏幕、卡片、撕页、网点、墨迹）。
2. **角色先动**：每一次运镜都由小片的动作触发；它不开门，镜头不进去。
3. **不穿实心**：相机不穿过没有开口的纸；开口必须先被角色打开。
4. **一镜一运动**：每个镜头节拍只有一种主运动（推、拉、跟、升、降、环绕、滚转）；不做无动机的推拉。
5. **速度有呼吸**：慢（0.3–0.6x）用于情绪，快（1.5–2x）用于转场；不允许匀速走完全片。
6. **焦点在角色或字**：景深永远服务于「看角色」或「读字」；背景可以虚，正文必须实。
7. **滚转即翻页**：每次穿过一页，镜头滚转 90° 或 180°；片尾回到视觉正面。
8. **光不变**：主光永远来自左上灯箱；红是唯一高饱和色；玉只出现一次。
9. **纸不变**：全片同一张纸的颗粒、纤维、套准偏移；不出现干净的数字渐变。
10. **结尾要落地**：最后 5 秒，镜头从 3D 世界拉回平面；所有滚转归零，观众回到纸面。

### 7.6 注意力与构图

- **一个节拍一个焦点**：每 2–4 秒只有一个视觉中心；其余层用景深、明度、运动虚化压下去。
- **三分之一法则**：小片永远在画面的左 1/3 或右 1/3，不居中；居中只给「肖像睁眼」「印章」两个时刻。
- **文字安全**：标题和数字不被角色遮挡；小片站在字的外侧、页边、标点上方。
- **视线引导**：红线的走向 = 观众的眼睛走向；每个镜头结尾，红线指向下一个开口。
- **密度节奏**：疏（封面 / 自述）→ 中（读片台 / 文章）→ 密（项目 / 知识库）→ 疏（自述 / 片尾）；不允许连续 12 秒高密度。
- **色彩节奏**：纸白 → 纸白 → 石墨 → 石墨 → 纸白 → 纸白 → 纸白 → 纸白 → 纸白；石墨只用在「证据 / 影院 / 雪崩」三段，形成呼吸。

### 7.7 焦点 / 景深 / 光

- **焦点**：跟拍时对在小片眼睛；读字时对在字；转场时对在开口边缘。不要「全画面都清楚」。
- **景深**：24mm 空间镜头 f/4，深景深；50mm 近景 f/2，浅景深；100mm 微距 f/4，焦点只有 2cm。
- **光**：主光左上 45°，暖白 3200K；补光右侧 10%，纸面反弹；红色元素自带 5% 自发光（用颜色提亮，不真的发光）。
- **阴影**：纸的阴影是暖褐色，不是黑色；角色脚下阴影 18% 墨色；印章下压时阴影扩大 2px。
- **暗场**：影院 / 知识库雪崩允许压到 85% 黑，但小片的纸白和红角必须可读。

## 8. 声音设计

### 8.1 声音哲学

**没有旁白。报告是安静的；唯一的人声是笔尖。**

前 44 秒，观众听到的是纸、灯箱、印章、胶片、键盘——一个被认真维护的系统；信息由等宽批注和衬线标题承担。第 45 秒，笔尖划纸的声音出现，手写「别找了。我在这儿。」——这不是配音，是**这个世界里第一次出现的心跳**。第 48 秒，印章落下，低频收束。

### 8.2 三音动机

站点的品牌声音是一个三音「扫描动机」。本片把它发展成整部片的音乐种子：

- **原形**：C5–G5–C6（523.25 / 783.99 / 1046.5 Hz），钟琴 / 钢片琴，短、清、略冷。
- **变奏**：
  - 序幕：单音 C5，像灯箱启动。
  - 读片台：完整三音，加纸打击乐。
  - 检查所见：三音下沉到低音区，变成盖章的节奏。
  - 能力链：三音被拉长，铺在胶片噪声下。
  - 文献索引：三音碎片化，像卡片翻动。
  - 文章：三音拨弦化，像打字机。
  - 简历：三音变慢，低八度，像心跳。
  - 自述：三音只剩一个 C5，悬着。
  - 签发：三音回到 C 大调，加低音提琴。
  - 片尾：C6 单音，纸声。

### 8.3 乐器与音色

- **纸**：纸张摩擦、翻页、折叠、撕裂、拍击；这是本片的主打击乐。
- **灯箱**：50Hz 嗡鸣、电流轻响、启辉器的「咔」。
- **印章**：90Hz 低频 + 纸面拍击 + 短混响。
- **胶片**：放映机齿轮、胶片摩擦、片门咔哒。
- **键盘 / 打字机**：文章段落的节奏。
- **钟琴 / 钢片琴 / 预置钢琴**：三音动机。
- **低音提琴 / 大提琴**：只在中后段出现，给「人」的温度。
- **笔尖**：全片唯一的「人声」；第 45 秒手写出现时，近场、干净、略慢。

### 10.2 字体

- 标题：Noto Serif SC Bold / Source Han Serif SC Heavy；120–240px；行高 0.95；字距 -0.02em。
- 正文：Noto Sans SC Regular；28–36px；行高 1.6。
- 标签：JetBrains Mono Regular；18–28px；字距 0.12em；全大写英文 + 中文。
- 手写：作者真实笔迹矢量；只有三处；不用字库手写体。
- 字体文件本地打包（SIL OFL），不引用 CDN；渲染前 `document.fonts.ready`。

### 10.3 纹理与质感

- 纸纹：400×400 灰度噪声，叠加 4–6%，随镜头轻微视差。
- 半调：网点 6–9px，45°，只出现在肖像、暗部、转场。
- 套准：每页左上角一个 1px 的十字套准线；红版偏移 1px。
- 墨迹：印章边缘有 0.5px 的毛边和 2–3 个飞墨点；不要做成完美矢量。
- 划痕：极少量，只在灯箱玻璃上；不要做成「复古滤镜」。

### 10.4 片头 / 片尾

- **片头**：无独立 logo 动画。报告封面 + `INCOMPLETE` 章 + 片名章，就是片头。
- **片尾**：纸面；左上红角；中间姓名 / 角色 / 数字 / 联系；右下墨色二维码；小片从印章后探头；底部制作信息。
- **片尾不出现**：大段感谢名单、社交图标墙、二维码以外的二维码、渐变背景。

### 10.5 海报

- **主海报**：报告封面，空白受检者，红角里探出小片的眼睛；片名章；底部「60s / 一镜到底 / 无旁白」。
- **竖版海报**：小片站在巨大的「?」上，背景是半调肖像的局部；适合朋友圈 / 小红书。
- **项目海报**：七张项目卡 + 红线，像一张接触印样。

### 10.6 竖版 / 方版改编

- **9:16 竖版（30s）**：封面 → 读片台标题 → 七张卡快切（仍是一镜，但相机路径更垂直）→ 知识库 30 → 肖像睁眼 / 手写 → 片尾卡。删掉影院、文章、简历的完整段，用 1–2 个镜头带过。
- **1:1 方版（15s）**：封面 → 小片画「?」→ 七张卡 → 肖像睁眼 / 手写 → 片尾。只保留「寻找 → 找到」。
- 竖版不是主片裁剪：重新设计相机路径，保证小片和字都在安全区。

## 11. 制作

### 11.1 技术路线

- **HyperFrames 工程**：`video/report-journey/`；一个根时间线，10 个房间子组合；相机 rig 在根上；角色 rig 在相机内。
- **3D 空间**：CSS 3D（`perspective` + `translateZ` + `rotate`）；每个房间是一张平面；相机是一个包裹层，改变 `transform` 和 `perspective-origin`；转场用 mask / clip-path 开口。
- **真实站点素材**：用 Playwright 以 2x 截取 `/`、`/work`、`/wiki`、`/posts`、`/resume`、`/about` 的关键区域；脱敏后作为纸面纹理；标题 / 数字用 HTML 重排，保证清晰。
- **角色**：SVG rig；`frame / corner / eye / legs / arms / satchel` 分组；GSAP 时间线；动作库复用；表情用 `scaleY` / `translateX` / `path`。
- **红线**：SVG path + `stroke-dashoffset`；在 3D 里做 2–3 层视差；转场时路径重绘。
- **手写**：作者真实笔迹矢量；用 `stroke-dashoffset` 逐笔画出；笔尖声与笔画同步。
- **声音**：`assets/audio/`；音乐 / 音效分层；最终混音输出 WAV，再编码 AAC。
- **渲染**：`npm run check` → `npm run render`；1080p / 24fps；输出 MP4 + WebM；逐帧检查转场。
