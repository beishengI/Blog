## 我信这几条

1. **先算账，再优化。** 训练看参数量、FLOPs、Dice、HD95；服务看首字时延、吞吐、显存。没有账本的优化只是换一版参数赌一把。
2. **判定与解释分离。** 模型可以负责抽取和对齐，但「过不过」要由规则给出。解释可以对话，判定表不能被动摇。
3. **低置信度转人工。** 错误的「OK」比缺失更危险。宁可让人多看两条。
4. **没做的事也写下来。** 每个项目都记录取舍，最贵的一栏往往是「没做的那一行」。
